# 🔐 Google OAuth Login with Node.js and Express

This is a basic Node.js application demonstrating how to implement **Google OAuth 2.0 authentication** using:

- Express
- Passport.js
- express-session

Users can log in with their Google account and view a simple profile page showing their name and email.

---

## 🚀 Features

- Login with Google using Passport.js
- Session handling with `express-session`
- Minimal, clean UI with embedded CSS
- Logout functionality
